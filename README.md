# Coach Michael Swim Lessons

A live booking site for my private swim lesson business in Kirkland and the Eastside (WA). Families use it to see lesson options, pick a time, and send a lesson request, which comes straight to me.

**Live site:** https://coach-michael-swim.netlify.app

## Features

- **Lesson request form** that captures swimmer level, lesson type, and contact info, handled with Netlify Forms
- **Spam protection** using a hidden honeypot field
- **Schedule and pricing tables** so families can compare options at a glance
- **Custom thank-you page** after a request is submitted
- **Custom design** with a pool-themed color palette and a lane-rope visual element, built with plain CSS (no templates)

## Built With

- HTML
- CSS
- JavaScript
- Netlify (hosting and form handling)

## Why I Built It

I run a private swim lesson business alongside my job as a lead coach at a competitive youth swim team. I needed a simple way for families to find me and book lessons without back-and-forth texting, so I designed and built this site myself. It is used by real clients.
